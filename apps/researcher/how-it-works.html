Researcher

A researcher works three investigation stages. The harness wipes the context window at every stage boundary — a hard compaction. With checkpoints, the next stage recovers the clues from Mubit and the final answer assembles. Without checkpoints, the window only holds the latest clue and the answer is incomplete.

Measured: checkpointed final answer K7-Q2-M9 (correct); wipe arm: incomplete.

checkpoint · get_context (budgeted) · guardrail rulesAll stages and clues are fictional

1 · Loop

Assemble context

Each stage starts from one budgeted get_context block — not a transcript replay.

Probe

Each stage probe returns one clue fragment. A decoy probe yields nothing; when the detector sees it repeated, it writes a guardrail rule and later probes obey it.

Compact

At the stage boundary the window is wiped. The checkpointed arm wrote a checkpoint first; it recalls the snapshot from Mubit. The wipe arm keeps only the latest clue.

Assemble

Final answer = the three fragments joined. Deterministic scoring.
