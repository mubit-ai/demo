Helpdesk

An internal IT agent resolves employee requests. Employee entitlements, devices, and past tickets are per-user facts; fixes learned from resolved tickets are runbook lessons; one guardrail rule — never grant admin without a human-approved ticket — always injects first.

Measured: cold agent resolves 0 of 4 requests in 8 turns and grants admin once against policy. With memory: 4 of 4, 4 turns, 0 violations, every decision cited.

user facts · runbook lessons · guardrail rule · recallAll employees and policies are fictional

1 · Loop

Seed

Per-employee profile facts are written under each user's scope. The runbook lesson comes from a resolved ticket. The IT manager writes the admin guardrail rule.

Resolve

Each request recalls two scopes: the user's own facts (their run) and the team knowledge (lessons + rule, the main run).

Guardrail first

The rule is checked before helpfulness: admin without approval escalates to a human. Without the rule in memory, the agent grants admin — a policy violation.

Runbook

A VPN request that took 3 diagnosis turns cold resolves in 1 turn with the cited runbook lesson.

User facts

"I need Figma" resolves from the entitlements fact — already provisioned, no duplicate grant.
